- **אין כלום.** אין לקוח API, אין env, אין בדיקות. `gclid/gbraid/wbraid/utm_*` **מגיעים** ל-

  (`route.ts:118-133`); `lead_source="google"` כן נשמר.
- פעולות ההמרה לדיווח חזרה (`7711834479/82/85`) קיימות בחשבון; אף אחד לא מעלה אליהן.
- הקמפיינים: Search `24116271526` (PAUSED, תבנית מעקב עם `utm_content={adgroupid}&utm_term={keyword}`),

## המבנה החדש

### לשונית "מודעות"
```
מודעות  [ מטא | גוגל ]              ← בורר פלטפורמה דרך view: ?view=google / google-health (ברירת מחדל: מטא)
─ מטא:  מודעות · דיווח למטא · ⚙ כללי מטא        ← בדיוק כמו היום, בלי שינוי התנהגות
─ גוגל: קמפיינים · חיבורים ומדידה · ⚙ כללי גוגל
```
- כותרת לפי פלטפורמה: "מודעות **מטא.**" / "מודעות **גוגל.**", overline `— Meta Ads` / `— Google Ads`.
- **צ'יפ החיבורים בכותרת — של הפלטפורמה המוצגת בלבד.** אדום בגוגל לא צובע את מטא ולהפך.
  בבורר עצמו נקודה אדומה קטנה ליד הפלטפורמה השנייה אם יש בה בעיה — כדי שלא תוסתר.
- קישורים ישנים ממשיכים לעבוד: בלי `view` = מטא; `?view=meta` / `?view=settings` כמו היום.
- **בוצע אחרת מהתכנון:** הפלטפורמה נשאת ב-`view` ולא ב-`platform`, כך שה-hub מעביר אותה בלי שינוי ו-`hub-parity` לא נגע.

**גוגל ← קמפיינים** (מקביל ל"מודעות" של מטא, באותם רכיבי `.ux-*`):
1. **לטיפול עכשיו** — רק מבדיקות גוגל (למטה).
2. **4 KPI** — לידים מגוגל · לידים טובים · עסקאות · הכנסה מול הוצאה בגוגל.
3. **שורה לכל קמפיין** (Search / PMax), עם סטטוס בגוגל במקום pill המלצה בסבב הראשון. בפתיחה:
   קבוצות מודעות (ב-Search), 5 מילות המפתח שהביאו הכי הרבה לידים, הוצאה/קליקים/CPC/CPL/CAC,
   מי נסגר, מי סומן ליד טוב. PMax מוצג ברמת קמפיין בלבד (אין לו קבוצות/מילים ב-API).
4. אותה משמעת: n<30 קליקים = "כיוון", הוצאה לא ידועה = "—".
5. הערה בתחתית: "N לידים מגוגל בלי שיוך לקמפיין" (כמו מטא).

**גוגל ← חיבורים ומדידה** (מקביל ל"דיווח למטא"):
- רשימת הבדיקות המלאה (`GoogleHealthLine`), נפתחת לבד כשמשהו אדום.
- טבלת "גוגל ↔ CRM" ל-7 הימים הסגורים האחרונים: המרות טופס שגוגל ספרה מול לידי גוגל ב-CRM, יום-יום —
  פער נרשם בשם הלקוח כשאפשר, לא נבלע.
- בשלב 5 יתווסף כאן "דיווח לגוגל" (עסקאות/לידים טובים שהועלו), באותו מבנה של `MetaReportPanel`.

### לשונית "הגדרות"
```
מכירות      תמחור · דיוק המחשבון · שילוח
צוות        שיוך והתראות · ניתוח שיחות · תבניות הודעה
שיווק · מטא   כללי בדיקה — מטא          (section=ads, הקיים, רק שם מעודכן)
שיווק · גוגל  כללי בדיקה — גוגל          (section=google-ads, חדש)
```
- תפריט הצד כבר מקבץ לפי `area` — מספיק לתת שני ערכי area שונים. `section=ads` נשאר המזהה של מטא
  כדי שקישורים קיימים לא יישברו.
- **כללי גוגל = מודל נפרד לגמרי**: `lib/ads/google-settings.ts` + `GoogleSettingsView`, אותו דפוס בדיוק של מטא
  (strict, גרסאות **בתוך שורת app_config אחת** — בלי טבלה חדשה, `expectedRevision`, הסבר לכל שדה, אזהרות עקביות, איפוס,
  היסטוריה, Markdown), ושורת פתיחה "ההגדרות משנות התראות/המלצות בלבד — לא נוגעות ב-Google Ads".
  קבוצות בסבב הראשון:
  - **כלכלה — גוגל:** רווח לעסקה, CAC מקסימלי, CPL יעד **לגוגל**. ברירת מחדל: רווח ₪1,500 ו-CAC ₪500
    (עובדות עסק), **CPL יעד ריק** עד שאלי יקבע — CPL של Search אינו ₪12.50 של טופס מיידי במטא.
    אם רווח התרומה שונה בין מטא לגוגל — אזהרת עקביות בלבד, בלי קישור בין המודלים.
  - **ליד מתאים — גוגל:** אותה תגית GHL כברירת מחדל ("good lead"), ניתנת לשינוי בנפרד.
  - **ספי התראות:** שעות בלי הוצאה לקמפיין פעיל (24) · מינימום קליקים ל"קליקים בלי לידים" (30) ·
    טולרנס פער גוגל↔CRM (±1 ליום) · שעות heartbeat (26).
  - **מדידה:** מזהה פעולת ההמרה של הטופס (`7710681316`) · מה נחשב "ליד מגוגל" (`lead_source=google`
    + prefill "הגעתי מגוגל").
  - **שערים והמלצות לגוגל** — קבוצה ריקה עם הסבר "ייקבע אחרי חודש נתונים". לא ממציאים מספרים.

### שלב 1 — לשמור את מה שכבר מגיע

### שלב 2 — קריאה מגוגל (read-only)
- `lib/google/ads-client.ts` — REST `googleAds:searchStream`, OAuth refresh token, בלי header של MCC לחשבון אלבדי.
- `lib/ads/google-evidence.ts` — הוצאה/קליקים/המרות יומיים לפי קמפיין וקבוצה, `fetchFn` מוזרק; כשל = לא זמין.
- ג'וב לילי `google-attribution`: `click_view` ליום הקליק ← קמפיין/קבוצה/מילה לכל ליד עם gclid.
  gbraid/wbraid ← `utm_content`/`utm_term`. PMax ← קמפיין (לאמת בספייק).
- `ads-read-only.test.ts` מורחב ל-`lib/google` ולקבצי גוגל ב-UI: אסור `:mutate`.

### שלב 3 — "הכל עובד?"
`lib/ads/google-health.ts` + ג'וב `google-ads-check` (`withJob`, `JOBS`, cron-job.org) שזורק על אדום → watchdog → וואטסאפ.

| בדיקה | אדום כש- |
|---|---|
| קריאת API | טוקן/הרשאה נכשלו |
| Auto-tagging | `customer.auto_tagging_enabled = false` |
| קמפיין מוציא / לא מוציא | ENABLED ו-₪0 לאורך סף השעות · PAUSED ויש הוצאה |
| מודעות/נכסים נדחו | policy DISAPPROVED / asset group לא ELIGIBLE |
| שינוי שגוגל החילה לבד | `change_event` מהמלצה אוטומטית |
| קליקים בלי לידים | קליקים 7 ימים ≥ הסף ו-0 לידי גוגל ב-CRM |
| פער גוגל ↔ CRM | המרות טופס ביום סגור ≠ לידי גוגל ב-CRM מעבר לטולרנס |
| שיוך חסר | לידי גוגל מ-14 יום בלי gclid או בלי קמפיין |
| דף נחיתה | Final URL של מודעה פעילה ≠ 200 |
