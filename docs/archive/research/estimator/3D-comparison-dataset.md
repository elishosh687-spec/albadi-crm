## נוסחת אלי (הרפרנס)
```
שטח = 2HW + 2HD + WD
מחיר = base_price × (שטח/base_שטח)^0.054 × (כמות/base_כמות)^0.008
       + 0.059×Δצבעים + 0.021×Δידית + 0.025×Δלמינציה
CBM/יח׳ = base_cbm × (שטח/base_שטח)^0.594
יח׳/קרטון = חציון של 7 הכי דומות, מעוגל ל-25
תיקון V2: base = חציון של K=5 בסיסים (לא אחד), אותו qty-tier, בלי חריגים/מגש
```
