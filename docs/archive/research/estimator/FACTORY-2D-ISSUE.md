## 🇨🇳 中文 — 致亚森工厂

**主题：关于平面袋（2D，无侧面/无底面）报价的疑问**

您好，

我们在整理平面袋（2D）的价目表时，发现价格存在几处不合逻辑的地方，希望您能帮忙澄清或提供一份更规范的价目表。

**当前平面袋基础价（无提手，1色，热压）：**

| 尺寸 (H×W cm) | 3000个 | 5000个 | 10000个 |
|---|---|---|---|
| H8×W10 | ¥0.53 | ¥0.55 | ¥0.37 |
| H10×W15 | ¥0.74 | ¥0.71 | ¥0.68 |
| H15×W20 | ¥0.53 | ¥0.55 | ¥0.37 |
| H25×W25 | ¥0.63 | ¥0.59 | ¥0.56 |
| H30×W40 | ¥0.70 | ¥0.55 | ¥0.46 |
| H35×W50 | ¥0.63 | ¥0.59 | ¥0.56 |

**四个问题：**

1️⃣ **价格不随尺寸增大而增加（有时反而更小的更贵）。**
例如 H10×W15（小）= ¥0.74，比 H35×W50（大很多）= ¥0.63 还贵。小袋子怎么会比大袋子贵？

2️⃣ **不同尺寸价格完全相同。**
H8×W10 和 H15×W20 价格完全一样（¥0.53 / 0.55 / 0.37）；H25×W25 和 H35×W50 也完全一样。尺寸差别很大，价格却一模一样，这正常吗？

3️⃣ **5000个比3000个还贵。**
H8×W10：3000个 = ¥0.53，但 5000个 = ¥0.55（更贵）。通常数量越多单价越低。（H15×W20 也是如此。）

4️⃣ **价目表没有覆盖客户实际常订的大尺寸。**
实际订单常见 H60×W45、H65×W55 等（比目录最大的 H35×W50 大很多），但目录里没有这些尺寸的价格。

**我们需要：** 一份规范的平面袋价目表 —
- 价格随面积（尺寸）合理递增；
- 数量越多，单价越低（单调）；
- 覆盖到较大尺寸（约到 H65×W55）。

这样我们才能给客户快速、准确地报价。谢谢！

## 🇮🇱 עברית — לאלי (רקע)

**למה אי אפשר לבנות נוסחה אוטומטית ל-2D:**

בניגוד לשקיות 3D (ששם המחיר עוקב יפה אחרי הגודל, ובנינו נוסחה מדויקת ~2%),
מחירון ה-2D של 亚森 **לא עקבי** — 4 סתירות:

1. **המחיר לא עולה עם הגודל.** H10×W15 הזעירה (¥0.74) יקרה מ-H35×W50 הענקית (¥0.63).
2. **מחירים זהים למידות שונות.** H8×W10 = H15×W20 בדיוק; H25×W25 = H35×W50 בדיוק.
3. **5000 יקר מ-3000.** H8×W10: 3000=¥0.53, 5000=¥0.55.
4. **הקטלוג לא מכסה את הגדלים שמזמינים** (H60×W45, H65×W55 — מעל המקסימום H35×W50).

**המסקנה:** בלי מחירון 2D מסודר מהמפעל, אי אפשר לתמחר 2D אוטומטית → 2D הולך למפעל.
ברגע שהמפעל ייתן מחירון מסודר (לפי גודל, מונוטוני בכמות, עד ~H65×W55) — נבנה נוסחה גם ל-2D.

*(שילוח 2D: לגדולות דווקא צפוי בערך, T≈0.55 ±10-15%; החוסם הוא המחיר.)*
